# Vulnerability Tracker API — Чек-лист

## Основные эндпоинты

- [x] **1. Добавление записи об уязвимости**
  - [x] Принимает название и уровень критичности
  - [x] Автоматически фиксирует дату добавления
  - [x] Возвращает идентификатор созданной записи
- [x] **2. Получение информации об уязвимости по ID**
  - [x] Возвращает полную информацию об уязвимости
  - [x] Корректный ответ при отсутствии записи (404)
- [x] **3. Запуск фоновой задачи сканирования**
  - [x] Принимает ссылку на репозиторий (например, GitLab)
  - [x] Сервис генерирует идентификатор задачи
  - [x] Возвращает ID задачи сканирования
  - [x] Сканирование выполняется асинхронно в фоне
- [x] **4. Получение статуса задачи сканирования по ID**
  - [x] Возвращает состояние: выполняется / завершена / ошибка
  - [x] Возвращает время последнего изменения статуса
  - [x] Возвращает результат сканирования, если задача завершена

## Обязательные требования

- [x] Сервис без постоянного хранилища (in-memory, каждый запуск — чистый лист)
- [x] Логирование запросов
- [x] Обработка ошибок
- [x] Unit-тесты
- [x] Документация, Swagger

## Задачи со звёздочкой (приоритет)

- [x] **1. Ограничение параллельного сканирования**
  - [x] Настраиваемый лимит одновременных сканирований
  - [x] Остальные запуски ставятся в очередь
  - [x] Статус «в очереди» для ожидающих задач
- [x] **2. Отмена сканирования**
  - [x] Эндпоинт возвращает идентификатор, время и успешность отмены
  - [x] Отмена сканирования, стоящего в очереди
  - [x] Прерывание уже запущенного сканирования
